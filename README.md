# Quantum-Assisted Harnesses for Verifiable AI Iteration

This public repository contains the bilingual research package for:

**Quantum-Assisted Harnesses for Verifiable AI Iteration: Candidate Search via Amplitude Amplification and Annealing**

Japanese title:

**検証可能なAIイテレーションのための量子支援ハーネス：振幅増幅とアニーリングによる候補探索**

The package is arXiv-ready, but this repository is the public release location. It includes the English manuscript, Japanese manuscript, reproducibility code, frozen numerical outputs, figures, and verification notes.

## Scope

The experiments are CPU simulations. The paper does not claim quantum advantage on current quantum hardware. The repository is intended to make the manuscript, numerical results, code, and bilingual materials easy to inspect and reproduce.
