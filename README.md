# Quantum-Assisted Harnesses for Verifiable AI Iteration

[English README](README.en.md) · [日本語 README](README.ja.md)

This repository is the public bilingual research package for:

**Quantum-Assisted Harnesses for Verifiable AI Iteration: Candidate Search via Amplitude Amplification and Annealing**

日本語題:

**検証可能なAIイテレーションのための量子支援ハーネス：振幅増幅とアニーリングによる候補探索**

It brings the manuscripts, reproducibility code, frozen numerical outputs, figures, and verification notes together in one inspectable package.

> **Scope and limitation:** The experiments are CPU simulations. This work does not claim quantum advantage on current quantum hardware.

## Reproducibility package

- [Code, frozen outputs, figures, and shared data](ai_quantum_bilingual_reformatted_latest/shared/)
- [Formatting and rebuild notes](ai_quantum_bilingual_reformatted_latest/README_FORMAT_REBUILD.md)

The numerical outputs are included so that readers can compare regenerated results against the package used for the manuscript. The repository is intended for inspection and reproducibility, not as evidence that current quantum hardware outperforms classical methods.
